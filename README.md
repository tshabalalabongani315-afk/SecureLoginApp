# SecureUserPortal

A modern ASP.NET Core 8 Razor Pages application that demonstrates secure user authentication and account management using ASP.NET Core Identity.

## Features

- Secure user registration
- Email confirmation with resend flow
- Forgot-password / reset-password flow
- User login and logout
- ASP.NET Core Identity authentication
- Password hashing
- User profile management
- Change password
- Event-driven activity logging (real Dashboard timeline)
- Two-factor authentication (TOTP authenticator apps)
- Profile photo upload (pluggable storage backend)
- Role-based authorization
- Dashboard for authenticated users
- Responsive UI
- SQL Server integration
- Entity Framework Core

## Getting Started

### Prerequisites

- Visual Studio 2022 or later
- .NET 8 SDK
- SQL Server LocalDB

### Installation

1. Clone the repository.

```bash
git clone https://github.com/<your-username>/SecureUserPortal.git
```

2. Open the solution in Visual Studio.

3. Update the database.

```powershell
Update-Database
```

4. Run the application.
